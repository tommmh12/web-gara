# Agents

Tai lieu nay mo ta cach su dung cac agent trong du an `web-gara`.

## Muc tieu

- Giu workflow nhat quan khi dung AI assistant.
- Uu tien thay doi nho, ro rang, de review.
- Khong commit thong tin nhay cam (token, mat khau, key, file `.env`).

## Nguyen tac lam viec

1. Doc hieu context truoc khi sua code.
2. Chi sua dung pham vi yeu cau, tranh dong vao file khong lien quan.
3. Sau khi sua, chay build/test phu hop de kiem tra.
4. Cap nhat tai lieu neu thay doi anh huong den cach van hanh.

## Quy tac Git

1. Dung commit message ngan gon, ro nghia.
2. Khong dua thu muc `target/`, file log, file tam, va cac file moi truong len Git.
3. Review lai danh sach file truoc khi commit.
